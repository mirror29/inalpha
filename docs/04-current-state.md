## 本次实现：统一准备新实验

- 页面与聊天走同一准备逻辑；页面通过普通 owner 鉴权接口检查，不调用聊天或生成模型。
- 参考真实 `available_at` 与闭合行情建议新窗口，显示原窗口、自然 60/20/20 切分和覆盖；不按收益挑窗，不修改原实验。
- 必要输入具备后冻结配置、事件快照、种子与行情摘要、模型和预算，再请求费用审批。修改参数需重新预检审批。
- E2 Loop 复用加密持久化批准命令；批准后直接提交，原操作可恢复读取。自定义 allow 规则不能绕过 Loop 费用确认。
- 增加迁移 `0067`，扩展批准命令工具约束；存在 Loop 批准记录时拒绝回滚，避免丢失恢复权。
- worker 在使用发现段之前检查完整行情和种子摘要，预检不替代执行端复核。
- 费用沿用统一用量账本，聊天、生成、修复与未知费用分开；没有生成不等于聊天免费。

部署后只读复核：服务器仓库为 `ab5fd15b`，Dashboard、Mastra、Evolver 的容器与发布回执一致且健康，数据库 `inalpha` 为 schema `0067`，Loop 记录仍为 0。准备入口已部署，正常 owner 操作验收仍待完成；不能因文档 SHA 变化重建服务。

本地测试边界：Evolver 335 通过 / 1 跳过，Dashboard 185 通过；编排最终有界全量运行 632 通过 / 7 失败 / 8 跳过，失败的三个文件单独重跑 11 通过。失败集中在子进程超时和墙钟断言，不能据重跑称本地全量零失败。随后精确业务 head CI `38036239879` 与合并版本 CI `38036966422` 均通过，具体版本映射见发布回执；CI 通过不替代正常 owner 或进程恢复验收。构建与一致性检查通过，既有一致性警告 12 条。

1. PR #219 的精确 head CI、主分支 CI、镜像构建、专项审查与三个服务部署已完成；保留旧镜像1dc8fa78和备份，Chrome 正常 owner 连接已恢复，免费准备与不足拦截已验收。
2. 待验收：冻结费用、单次批准、刷新和响应丢失后的原操作恢复，以及英文与移动页面。中文桌面免费准备、结构化阻塞、UI 参数修改使旧结果隐藏已由 Chrome 辅助功能操作既有 owner 会话验证，不代表用户手工验收。
3. 核对实际新窗口、来源首次可见时间、闭合连续行情与必要覆盖。输入不足时继续真实采集；不重跑相同付费搜索、不改写历史窗口。

### P0 · 可靠性与真实五代搜索

- 已有自动化和隔离数据库的租约、幂等、审批恢复、交接测试。完整服务进程退出、在途模型请求、显式失败重试、旧 worker 隔离仍需独立服务验收；数据库对象重建不等于生产重启通过。
- 故障注入先在同版本隔离环境进行。生产在安全维护范围复核，不为验证中断在途用户任务或持续采集。
- 新实验输入与正常 owner 授权可用后，运行有界五代搜索，记录数据摘要、有效变异率、重复代码、拒绝原因、匹配对照、FDR、费用与耗时。
- 无冠军是可接受的研究结果；不能将“候选生成成功”写成“策略改善”。

### P0 · 冠军后的长期证据

- 冠军锁定并幂等交接同一 Forward sandbox。
- 累积至少 30 个真实日与 3 个独立事件，之后才允许一次性 holdout；验证重复请求与交接不会重复消费。
- 最终采用由用户明确选择。没有真实冠军时，不伪造 Forward 起点或采用资格。

### P1 · 按运行证据优化

- 按资产、来源与首次可见时间展示覆盖缺口，依据缺口补数据源，避免只增加新闻数量。
- 汇总真实变异有效率、消融、匹配失败、FDR、已知和未知费用，决定评估调整。
- 保持任务、attempt、审批、费用、冠军和验证证据可追溯；哈希只作为诊断信息。
- MAP-Elites、Island Model、更多因子 agent 后置。
